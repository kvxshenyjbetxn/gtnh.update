# GTNH Updater

Окрема десктопна програма для підготовки оновлень **GregTech: New Horizons** зі збереженням вибраних файлів клієнта та сервера.

## Можливості

- Каталог офіційних релізів GTNH із вибором варіанта Java та завантаженням прямо у програмі.
- Одночасне завантаження кількох архівів клієнта й сервера, різних версій і варіантів Java.
- Прогрес, скасування й повторна спроба — у рядку відповідного файлу. Клієнтські завантаження видно лише на вкладці клієнта, серверні — на серверній; перемикання вкладок їх не зупиняє.
- Архіви зберігаються в `downloads` у папці конфігурації користувача. Незавершені `.part` прибираються після скасування або помилки; готовий `.zip` видаляється лише після успішного встановлення. При помилці або скасуванні плану архів залишається.
- Встановлення завантаженої збірки в новий інстанс Prism або окрему серверну папку з перенесенням увімкнених правил. Папки об’єднуються без видалення нових файлів; заміни показуються до підтвердження, конфлікти «Запитувати» потребують вибору.
- Безпечне розпакування без символічних посилань і виходу за каталог, перевірка вільного місця та окрема тимчасова підготовка. Стару збірку й наявні папки призначення програма не перезаписує.
- Автоматичне збереження налаштувань, зокрема теми, мови, папки Prism, правил перенесення та перемикача стабільних і beta/RC версій.
- Збереження статистики гри зі старого `instance.cfg` та синхронізація назви нового інстансу у Prism з назвою, введеною перед встановленням. Інші параметри нової збірки не замінюються старими.
- Окремі правила перенесення для клієнта й сервера: стандартні за вікі та власні.
- Вибір файлів і папок через системний діалог, налаштування дій при конфліктах.
- Українська й англійська мови, світла та чорна AMOLED теми.

## Встановлення

Спочатку в **Налаштуваннях → Папка інстансів Prism** один раз оберіть папку `instances` — налаштування збережуться автоматично. Вона буде початковим розташуванням для вибору старого інстансу й місцем встановлення нового. Власний шлях підтримує portable Prism. Для сервера папка призначення обирається окремо. Якщо папку Prism не задано або вона недоступна, майстер відкриває налаштування для її вибору.

Оновлення відбувається на одній сторінці з чотирма послідовними секціями. **«Продовжити»** згортає поточну секцію в короткий підсумок і відкриває наступну; натискання на заголовок завершеного етапу повертає до редагування.

1. **Стара збірка.** Оберіть старий інстанс Prism / `.minecraft` або папку сервера. Стару збірку програма не змінює.
2. **Нова збірка.** Завантажте реліз із каталогу, оберіть Java й після завершення натисніть **«Обрати цю збірку»**. Або оберіть **«Збірка вже завантажена» → «Обрати ZIP» / «Обрати папку»** — відкриється стандартне системне вікно. Власного файлового браузера немає. Прогрес завантаження не губиться при згортанні секції.
   Для клієнта потрібен повний архів/інстанс Prism із `instance.cfg` та `mmc-pack.json`, для сервера — папка/архів із `mods` і `config`. Вибраний користувачем ZIP чи папка **ніколи не видаляється й не змінюється**. Якщо нова збірка має нестандартний `instance.cfg` з іменованими секціями, але без `ConfigVersion`, спочатку відкрийте й збережіть її у Prism: встановлення такого неоднозначного формату блокується. З аналогічного старого файлу статистика не переноситься.
3. **Що перенести.** Перегляньте кількість увімкнених правил, розгорніть **«Усі правила та власні файли»**, якщо потрібно змінити вибір. Зміни правил зберігаються автоматично.
4. **Перевірка та встановлення.** Перевірте збірки й правила, папку призначення та назву **нової, ще неіснуючої** папки. Для клієнта введена назва також записується в `instance.cfg` і відображається у Prism; награний час та час останнього запуску успадковуються зі старого інстансу, якщо знайдено коректні значення. Папка Prism береться з налаштувань без повторного вибору в майстрі; для сервера місце обирається тут. Натисніть **«Підготувати й перевірити»**, перегляньте фактичний список файлів і папок (включно з порожніми), вирішіть конфлікти й окремо підтвердьте перенесення. План можна скасувати; під час розпакування й копіювання потрібно дочекатися завершення. Поки операція активна, змінювати збірки й правила не можна; налаштування можна переглянути без втрати прогресу.

Після завершення запустіть новий інстанс у Prism (перезапустіть Prism, якщо інстанс не з’явився) або вручну перенесіть нову серверну папку на сервер.

Закрийте Minecraft / зупиніть старий сервер перед копіюванням і зробіть резервну копію світу. Ігрові файли копіюються **лише за зазначеними правилами** (статистика Prism переноситься окремо): стандартне серверне правило переносить тільки `config/JourneyMapServer`; світ та адміністративні файли додайте власними правилами, якщо вони потрібні. Не переносіть старі `mods` або весь `config` без перевірки сумісності.

Java не встановлюється, Minecraft/сервер не запускаються, EULA не приймається автоматично. Перенесення світу не замінює його запуск у проміжних гілках GTNH. Стан завантажень зберігається лише у поточному сеансі програми. Після перезапуску наявний ZIP можна вибрати через «Обрати ZIP» — повторне завантаження не потрібне.

**У розробці:** автоматична перевірка оновлень GTNH.

Цільові платформи — **macOS, Windows і Linux**. Наразі збірку перевірено на macOS.

Незалежний проєкт, не офіційний продукт команди GTNH. Перед оновленням зберігайте резервну копію світу.
