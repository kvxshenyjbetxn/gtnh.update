# GTNH Updater

Окрема десктопна програма для підготовки оновлень **GregTech: New Horizons** зі збереженням вибраних файлів клієнта та сервера.

## Можливості

- Каталог офіційних релізів GTNH із вибором варіанта Java та завантаженням прямо у програмі.
- Одночасне завантаження кількох архівів клієнта й сервера, різних версій і варіантів Java.
- Прогрес, скасування й повторна спроба — у рядку відповідного файлу. Клієнтські завантаження видно лише на вкладці клієнта, серверні — на серверній; перемикання вкладок їх не зупиняє.
- Архіви зберігаються в `downloads` у папці конфігурації користувача. Незавершені `.part` прибираються після скасування або помилки; готовий `.zip` видаляється лише після успішного встановлення. При помилці або скасуванні плану архів залишається.
- Встановлення завантаженої збірки в новий інстанс Prism або окрему серверну папку з перенесенням увімкнених правил. Папки об’єднуються без видалення нових файлів; заміни показуються до підтвердження, конфлікти «Запитувати» потребують вибору.
- Безпечне розпакування без символічних посилань і виходу за каталог, перевірка вільного місця та окрема тимчасова підготовка. Стару збірку й наявні папки призначення програма не перезаписує.
- Збережений перемикач стабільних і beta/RC версій.
- Окремі правила перенесення для клієнта й сервера: стандартні за вікі та власні.
- Вибір файлів і папок через системний діалог, налаштування дій при конфліктах.
- Українська й англійська мови, світла та чорна AMOLED теми.

## Встановлення

1. Виберіть поточну збірку та увімкніть потрібні правила перенесення. Незбережені зміни правил теж враховуються.
2. Завантажте вибраний реліз і варіант Java та натисніть **«Встановити й перенести файли»** у рядку архіву. Або натисніть єдину кнопку **«Обрати збірку»** у блоці «Збірка вже завантажена»: один список підтримує і локальні ZIP, і папки. Подвійне натискання відкриває папку, «Обрати збірку» підтверджує вибраний ZIP/папку (або поточну відкриту папку).
   Для клієнта потрібен повний архів/інстанс Prism із `instance.cfg` та `mmc-pack.json`, для сервера — папка/архів із `mods` і `config`. Локальна збірка спочатку копіюється у тимчасове місце: вибраний користувачем ZIP чи папка **ніколи не видаляється й не змінюється**.
3. Для клієнта виберіть папку `instances` вашого Prism Launcher; для сервера — батьківську папку результату. Вкажіть назву **нової, ще неіснуючої** папки.
4. Натисніть **«Розпакувати й підготувати перенесення»**, перевірте список, виберіть дії для конфліктів і підтвердьте перенесення. На етапі перегляду можна скасувати операцію; під час розпакування й копіювання потрібно дочекатися завершення.
5. Запустіть новий інстанс у Prism (перезапустіть Prism, якщо інстанс не з’явився) або вручну перенесіть нову серверну папку на сервер.

Закрийте Minecraft / зупиніть старий сервер перед копіюванням і зробіть резервну копію світу. Копіюються **лише зазначені правила**: стандартне серверне правило переносить тільки `config/JourneyMapServer`; світ та адміністративні файли додайте власними правилами, якщо вони потрібні. Не переносіть старі `mods` або весь `config` без перевірки сумісності.

Java не встановлюється, Minecraft/сервер не запускаються, EULA не приймається автоматично. Перенесення світу не замінює його запуск у проміжних гілках GTNH. Стан завантажень зберігається лише у поточному сеансі програми. Після перезапуску наявний ZIP можна вибрати через «Обрати збірку» — повторне завантаження не потрібне.

**У розробці:** автоматична перевірка оновлень GTNH.

Цільові платформи — **macOS, Windows і Linux**. Наразі збірку перевірено на macOS.

Незалежний проєкт, не офіційний продукт команди GTNH. Перед оновленням зберігайте резервну копію світу.
